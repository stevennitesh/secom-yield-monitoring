# 04.2.5 Phase 3 Final Refit and Threshold Derivation

## Scope

Phase 3 produces the frozen supervised models and their lockbox-eligible thresholds.

## Inherited Constraints

1. Phase 3 operates only on the role-level frozen configs produced by [04.2.4 Phase 2 Hyperparameter Freeze](04.2.4-phase-2-hyperparameter-freeze.md).
2. Phase 3 derives thresholds under the cross-cutting rules in [06 Threshold Policy](../06-threshold-policy.md); it does not redefine those rules locally.

## Final Refit and Threshold Procedure

1. Refit frozen primary config on full DEV with seed `42`.
2. Refit frozen challenger config on full DEV with seed `42` if available.
3. Derive scientific and operational thresholds from full-DEV in-sample predictions for each available frozen model.
4. Only these Phase-3 frozen models are lockbox-eligible supervised models.
