# 00 Status and Provenance

## Scope

This document explains where the canonical SECOM spec came from and how to interpret the modular split.

## Normative Statements

1. This modular spec supersedes the legacy monolithic file `docs/final_end_to_end_report_strategy_merged.md`.
2. The modular spec consolidates the merged strategy material from:
   1. `docs/report_strategy/final_end_to_end_report_strategy.md`
   2. `docs/report_strategy/agreed_all_selector_multiseed_changes.md`
3. If any older strategy text conflicts with a file under `docs/spec/`, the `docs/spec/` file wins.
4. Runbooks under `docs/report_strategy/runbooks/` are implementation aids. If a runbook conflicts with the modular canonical spec, the modular canonical spec wins.
5. Historical review, challenge, and critique documents in `docs/report_strategy/` are retained for audit history and design rationale. They are not the active source of truth.
