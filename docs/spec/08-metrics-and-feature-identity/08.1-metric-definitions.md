# 08.1 Metric Definitions

## Lane A Core Metrics

1. BER, True+, True-.
2. Mean, std, and 95% CI across folds computed from `lane_a_global_fold_metrics.csv` under one selected global-OOF config per `(selector, classifier, replication_mode)`.
3. Lane A CI method is fixed: 95% percentile bootstrap CI for the mean metric across folds (`n_boot=1000`, seed `42`):
   1. bootstrap resample the 10 fold indices with replacement,
   2. recompute the unweighted mean metric across the resampled folds,
   3. take the 2.5th and 97.5th percentiles of the bootstrap mean distribution.

## Lane B and Lockbox Core Metrics

1. BER, True+, True-.
2. ROC-AUC, PR-AUC.
3. MCC, F2.
4. Lane B: fold-wise values and mean+/-std.
5. Lockbox: point estimates only.
6. Metric computation definitions (reporting only, not used for selection unless explicitly stated elsewhere):
   1. `ROC_AUC = sklearn.metrics.roc_auc_score(y_true=y_bin, y_score=p_hat)`.
   2. `PR_AUC = sklearn.metrics.average_precision_score(y_true=y_bin, y_score=p_hat)` (average precision, not trapezoid PR integral).
   3. `MCC = sklearn.metrics.matthews_corrcoef(y_true=y_bin, y_pred=y_pred)`.
   4. `F2 = sklearn.metrics.fbeta_score(y_true=y_bin, y_pred=y_pred, beta=2, pos_label=1, zero_division=0)`.

## Core Metric Definition

1. `BER = 0.5*(FNR + FPR)`.
2. With `True+ = TPR` and `True- = TNR`, `BER = 1 - 0.5*(True+ + True-)`.

## MSPC Metrics and Evaluation Boundary

1. MSPC baseline comparison is part of the canonical metric surface.
2. MSPC fold discipline for outer folds:
   this subsection governs the outer-fold MSPC evaluation path; Section 07 governs the separate lockbox MSPC companion evaluation.
   1. fit MSPC on each outer-train pass subset only,
   2. score corresponding outer-test set,
   3. union alarm stream rule: `alarm = (T2 > UCL_T2) OR (Q > UCL_Q)`.

## Report-Level Diagnostics

These diagnostics are part of the report narrative, but this section does not define separate dedicated artifact schemas for them unless another section does so explicitly.

1. Brier and calibration diagnostics.
2. Weekly alarm burden and fail capture/miss counts.
3. Cost curves.
4. Feature stability and redundancy diagnostics.
5. Brier dual baselines per evaluation slice prevalence `p`:
   1. all-pass baseline=`p`,
   2. prevalence-constant baseline=`p*(1-p)`.

## Decision Outputs

1. Lane A core metric outputs:
   1. `reports/lane_a_global_fold_metrics.csv` is the canonical fold-level output for Lane A BER / True+ / True-,
   2. `reports/lane_a_global_summary.csv` is the canonical summary output for Lane A means, standard deviations, and CIs.
2. Lane B supervised metric outputs:
   1. `reports/splitwise_timeaware_results.csv` is the canonical tuple-level output for Stage B outer-test BER / True+ / True-,
   2. `reports/timeaware_model_selection.csv` is the canonical method-level summary output over `(outer_fold, seed)`.
3. Lockbox supervised metric outputs:
   1. `reports/final_lockbox_result.csv` is the canonical output for lockbox BER / True+ / True- / ROC-AUC / PR-AUC / MCC / F2 and matched `TNR=90%` reporting.
4. MSPC metric outputs:
   1. `reports/mspc_baseline.csv` is the canonical output for MSPC outer-fold and lockbox metric reporting.
5. Report-level diagnostic outputs:
   1. `reports/operational_cost_curves.csv` is the canonical output for cost-curve reporting,
   2. `reports/manager_facing_outputs.csv` is the canonical output for manager-facing weekly workload, fail-capture, and predicted-flag-fraction summaries,
   3. feature stability and redundancy diagnostics are governed by [08.2 Feature Stability and Identity](08.2-feature-stability-and-identity.md) and its downstream artifacts.
