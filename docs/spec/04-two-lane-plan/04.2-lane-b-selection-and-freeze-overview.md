# 04.2 Lane B Selection and Freeze Overview

## Scope

Lane B is the deployment-realistic supervised-model path. It uses temporal validation on DEV, freezes one primary model and an optional challenger, and evaluates the frozen models on the lockbox only after threshold freeze.

## Stage Flow

1. Define the DEV-only outer time-aware folds.
2. Run Stage A as a diagnostic-only baseline on those folds.
3. Run Stage B nested CV to select methods under time-aware evaluation.
4. Rank methods and choose the primary model plus optional challenger.
5. Run Phase 2 repeated inner CV on full DEV to freeze one config per available role.
6. Run Phase 3 full-DEV refit and derive the frozen scientific and operational thresholds.
7. Hand the frozen models to the lockbox and drift-gate protocol.
