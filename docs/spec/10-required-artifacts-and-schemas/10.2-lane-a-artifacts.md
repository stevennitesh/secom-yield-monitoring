# 10.2 Lane A Artifacts

## `reports/lane_a_global_sweep.csv`

1. One row per evaluated `(selector, classifier, replication_mode, config_tuple)`.
2. Required columns are:
   `selector`, `classifier`, `replication_mode`, `alpha`, `gamma`, `C`, `n_neighbors`,
   `threshold_oof_global`, `mean_BER_oof`, `std_BER_fold`, `mean_True+_oof`, `mean_True-_oof`,
   `mean_n_selected_features`, `min_n_selected_features`, `max_n_selected_features`, `n_folds`.
3. `classifier` values must match the active Lane A classifier run set, `selector` values must match the active selector run set, and `replication_mode` values must be exactly `strict` or `with_missing_indicators`.

## `reports/lane_a_global_best_config.csv`

1. Exactly one row per `(selector, classifier, replication_mode)`.
2. Required columns are:
   `selector`, `classifier`, `replication_mode`, `alpha`, `gamma`, `C`, `n_neighbors`,
   `threshold_oof_global`, `mean_BER_oof`, `std_BER_fold`, `mean_True+_oof`, `mean_True-_oof`,
   `mean_n_selected_features`, `min_n_selected_features`, `max_n_selected_features`, `n_folds`,
   `n_configs_evaluated`.
3. Exact row count is `n_selectors * n_classifiers * 2`, where the factor `2` comes from the two replication modes.
4. Every best-config row must correspond to a config that also appears in `reports/lane_a_global_sweep.csv`.

## `reports/lane_a_global_fold_metrics.csv`

1. One row per `(selector, classifier, replication_mode, fold)` for the selected best config.
2. Required columns are:
   `selector`, `classifier`, `replication_mode`, `fold`,
   `BER`, `True+`, `True-`,
   `n_train`, `n_test`, `n_test_fails`, `n_selected_features`,
   `threshold_oof_global`, `alpha`, `gamma`, `C`, `n_neighbors`.
3. Each `(selector, classifier, replication_mode)` triplet must include exactly 10 distinct folds.
4. `fold` values must be exactly `1..10`.
5. Duplicate `(selector, classifier, replication_mode, fold)` rows are not allowed.

## `reports/lane_a_global_ablation.csv`

1. Columns: `selector`, `classifier`, `BER_strict`, `BER_MI`, `delta_BER`, `CI_lower`, `CI_upper`, `n_boot`.
2. Sign convention is fixed: `delta_BER = BER_strict - BER_MI` (positive means missing indicators improved BER).
3. `CI_lower` and `CI_upper` correspond to the same signed delta definition.
4. `CI_lower` and `CI_upper` are the 95% percentile paired bootstrap CI for the mean `delta_BER` across folds (`n_boot=1000`, seed `42`):
   resample fold indices with replacement, recompute the unweighted mean `delta_BER` over resampled folds, then take the 2.5th and 97.5th percentiles.
5. Exact row count is `n_selectors * n_classifiers`.

## `reports/lane_a_global_summary.csv`

1. One row per `(selector, classifier, replication_mode)` where `replication_mode in {'strict','with_missing_indicators'}`.
2. Required columns are:
   `selector`, `classifier`, `replication_mode`, `n_folds`, `n_boot`, `boot_seed`,
   `mean_BER`, `std_BER`, `CI_lower_BER`, `CI_upper_BER`,
   `mean_True+`, `std_True+`, `CI_lower_True+`, `CI_upper_True+`,
   `mean_True-`, `std_True-`, `CI_lower_True-`, `CI_upper_True-`.
3. Exact row count is `n_selectors * n_classifiers * 2`.
4. CI method is fixed: 95% percentile bootstrap CI for the mean metric across folds (`n_boot=1000`, seed `42`), consistent with [08.1 Metric Definitions](../08-metrics-and-feature-identity/08.1-metric-definitions.md).
5. If `classifier='krr'` is part of the active Lane A run set, this artifact must contain exactly one row each for:
   1. `(selector='F-test', classifier='krr', replication_mode='strict')`,
   2. `(selector='F-test', classifier='krr', replication_mode='with_missing_indicators')`.

## `reports/lane_a_global_full_fit_summary.csv`

1. One row per `(selector, classifier, replication_mode)`.
2. Required columns are:
   `selector`, `classifier`, `replication_mode`, `alpha`, `gamma`, `C`, `n_neighbors`,
   `threshold_oof_global`, `threshold_full_dataset`,
   `BER_full_dataset`, `True+_full_dataset`, `True-_full_dataset`,
   `n_samples_full_dataset`, `n_fails_full_dataset`, `n_selected_features_full_dataset`,
   `threshold_full_dataset_role`.
3. Exact row count is `n_selectors * n_classifiers * 2`.
4. `threshold_full_dataset_role` must be `diagnostic_only`.
5. `threshold_full_dataset` is derived from the selected-config full-data refit using the Section 06 shared BER-optimal threshold rule on the full-dataset in-sample `(y_bin, score)` pairs.
